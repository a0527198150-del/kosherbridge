# גשר כשר 🎧

אפליקציית אנדרואיד שמחברת **נגן אנדרואיד** (קופסת אנדרואיד, טאבלט, נגן רכב) ל**טלפון כשר** דרך בלוטוס,
כך שכל השיחות של הטלפון הכשר מופיעות על הנגן — ואפשר **לענות, לדחות ולחייג** דרכו, עם אפליקציית **אנשי קשר** מובנית.

## איך זה עובד

הנגן מתנהג כמו **מערכת דיבורית לרכב** (פרוטוקול Bluetooth HFP בתפקיד Hands-Free Client):

```
📶 טלפון כשר (ליד החלון)  ←—HFP/BT—→  🎧 נגן אנדרואיד (בבית)
        │                                    │
   קליטה + SIM                    מסך שיחה, חיוג, אנשי קשר
```

- שיחה נכנסת לטלפון הכשר → הנגן מצלצל במסך מלא עם כפתורי **ענה / דחה**.
- חיוג מהנגן → השיחה יוצאת **דרך כרטיס ה-SIM של הטלפון הכשר**.
- השמע עובר דרך הרמקול/מיקרופון של הנגן (SCO).

## דרישות

1. **הנגן** צריך לתמוך בפרופיל HFP Client (דיבורית). מתאים לרוב קופסאות האנדרואיד, נגני הרכב והטאבלטים.
   *בטלפון רגיל הפרופיל מוסתר — בדקו בטאב "הגדרות → כל הגדרות החיבור → אבחון" אם כתוב "נתמך".*
2. **הטלפון הכשר** — כל טלפון עם בלוטוס רגיל (הוא מתנהג כ-Audio Gateway).
3. אנדרואיד 7 ומעלה (minSdk 24).

## התקנה

1. הורידו את קובץ ה-APK האחרון מהריצה בגיטהאב — ארטיקט `kosherbridge-apk`.
2. העבירו את ה-APK לנגן (בכבל USB, כונן רשת, או הורדה ישירה).
3. התקינו — מאשרים "התקן מיישומים לא מוכרים" אם צריך.
4. בפתיחה הראשונה, האפליקציה תבקש:
   - **בלוטוס** — חובה (לחיבור לטלפון הכשר)
   - **התראות** — חובה (להצגת שיחות נכנסות)
   - **אנשי קשר** — אופציונלי (לייבוא אנשי קשר מהנגן)
   - **מיקום** — באנדרואיד ישן בלבד (לסריקת מכשירים)

> ⚠️ **חשוב:** אם דוחים הרשאה — האפליקציה תציג הודעה. אפשר להפעיל מחדש דרך הגדרות ← אפליקציות ← גשר כשר ← הרשאות.

## חיבור — צעד אחר צעד

### שלב 1: זיווג המכשירים

**חייבים לעשות את זה פעם אחת בלבד.** אחרי זה החיבור אוטומטי.

**דרך א' — זיווג דרך האפליקציה (מומלץ):**
1. פתחו את **הגדרות** באפליקציה.
2. לחצו על **כל הגדרות החיבור**.
3. לחצו על **"צימוד מכשיר חדש (סריקה)"**.
4. בטלפון הכשר: פתחו הגדרות בלוטוס ← הפיכו לנראה/גלוי.
5. בנגן: המתינו שהטלפון יופיע ברשימה (10-15 שניות).
6. לחצו על שם הטלפון ברשימה.
7. בשני המכשירים: אשרו את בקשת הזיווג (קוד 6 ספרות זהה).

**דרך ב' — זיווג דרך הגדרות האנדרואיד:**
1. בנגן: הגדרות ← בלוטוס ← סריקה.
2. בטלפון הכשר: הפעילו בלוטוס, הפכו לגלוי.
3. כשהטלפון מופיע — לחצו עליו.
4. אשרו את קוד הזיווג בשני המכשירים.

### שלב 2: בחירת המכשיר באפליקציה

1. באפליקציה: **הגדרות ← כל הגדרות החיבור ← "בחר מכשיר"**.
2. הטלפון הכשר אמור להופיע ברשימה (אם זווגתם אותו).
3. לחצו עליו.
4. האפליקציה תתחבר אוטומטית — **חפשו את סימן האוזנייה בטלפון הכשר** (📞🎧 או אייקון דיבורית בשורת המצב).

### שלב 3: וידוא שהכל עובד

1. **בטלפון הכשר:** אמור להופיע סימן אוזנייה / דיבורית למעלה.
2. **באפליקציה:** במסך הבית — הסטטוס אמור להראות **"מחובר"** (ירוק) + שם הטלפון.
3. **בדיקת שיחה:** חייגו מהטלפון הכשר למספר אחר (או בקשו ממישהו לחייג אליו) — השיחה אמורה להופיע על הנגן במסך מלא.

### שלב 4: מיקום

הניחו את הטלפון הכשר במקום עם **קליטה סלולרית טובה** (ליד חלון), במרחק של עד ~10 מטר מהנגן. בלוטוס לא עובר קירות עבים.

## פתרון בעיות: "מתחבר לכמה שניות ומתנתק" 🔥

זה התסמין הנפוץ ביותר. הסיבה והפתרון:

**הסיבה:** כשהנגן מזווג לטלפון, מערכת האנדרואיד מנסה להתחבר אליו אוטומטית. הטלפון הכשר תומך בחיבור דיבורית **אחד בלבד** — והמערכת תופסת אותו, והאפליקציה נופלת.

**הפתרון — חייבים לעשות את זה פעם אחת (במיוחד אחרי עדכון גרסה):**

1. **מחקו את הזיווג משני הצדדים:**
   - בנגן: הגדרות ← בלוטוס ← על שם הטלפון ← הסר/שכח.
   - בטלפון הכשר: הגדרות בלוטוס ← על שם הנגן ← הסר.
2. **זווגו מחדש** — לפי שלב 1 למעלה.
3. בחרו את הטלפון באפליקציה — לפי שלב 2.

**למה זה עוזר:** האפליקציה מנטרלת את החיבורים המערכתיים **ברגע הזיווג**. בזיווג ישן, הנטרול לא התרחש — ולכן החיבור נפל.

### אבחון עצמי

אם עדיין נופל:
1. באפליקציה: **הגדרות ← כל הגדרות החיבור ← אבחון ← "העתק דוח אבחון"**.
2. הדביקו את הדוח בתמיכה — הוא מראה בדיוק:
   - איזה נגן (יצרן/דגם/אנדרואיד)
   - מתי החיבור נפל (אחרי כמה שניות)
   - כמה ניתוקים היו
   - איזה שער בלוטוס נפתח (HFP / אוזנייה)

### אפשרויות נוספות אם RAW לא מספיק

במקרים נדירים (נגנים ישנים מאוד, או שבבי בלוטוס לא סטנדרטיים):

1. **Shizuku** (דורש התקנה חד-פעמית, בלי רוט):
   - התקינו את אפליקציית Shizuku.
   - בנגן: הגדרות ← אפשרויות מפתחים ← הפעילו "ניפוי שגיאות אלחוטי".
   - ב-Shizuku: "זיווג" ← הזינו את הקוד. "הפעל".
   - באפליקציה שלנו: הגדרות ← כל הגדרות החיבור ← ערוץ חיבור ← Shizuku.

2. **רוט בנגן (הרשאת su — בלי Shizuku ובלי מודול)**: האפליקציה תומכת בערוץ
   **"דרך הרשאת רוט (su)"** — אם הנגן מרוט (Magisk, KernelSU או כל ניהול root)
   והאפליקציה קיבלה הרשאת root, היא מריצה בעצמה תהליך מורשה (app_process תחת
   uid 0) שמשתמש בפרופיל הדיבורית המלא. אין צורך באף אפליקציה נוספת:
   - בנגן: הגדרות ← כל הגדרות החיבור ← ערוץ חיבור ← **"דרך הרשאת רוט (su)"**.
   - בפעם הראשונה יופיע חלון אישור של ניהול ה-root (Magisk/אחר) — מאשרים.
   - **הערוץ משמש רק אם בחרתם אותו במפורש** — במצב אוטומטי (AUTO) ובערוץ הישיר
     האפליקציה לא נוגעת ברוט בכלל; כשהערוץ הישיר נחסם, היא עוברת אוטומטית
     רק ל-Shizuku.
   - ההרשאה נשמרת, כך שהערוץ עובד גם אחרי אתחול (בניגוד ל-Shizuku האלחוטי).

3. **רוט בנגן + מודול Magisk** (עובד לנצח, גם אחרי אתחול, בלי להעניק הרשאה
   לכל אפליקציה):
   - התקינו Magisk בנגן.
   - הורידו את ארטיקט `kosherbridge-magisk-module` מהריצה בגיטהאב.
   - התקינו את המודול דרך Magisk ← אתחול.
   - הפרופיל המלא (HFP Client) עובד באפליקציה עצמה — כולל קול, בלי Shizuku.

## מגבלות חשובות

- ה-API שמאפשר לשלוט בשיחות (`BluetoothHeadsetClient`) הוא API **מוסתר** של אנדרואיד.
  האפליקציה ניגשת אליו ב-reflection עם fallback ל-polling, וזה עובד ברוב מכשירי הנגן/קופסאות האנדרואיד.
  במכשירים עם אכיפה הדוקה (אנדרואיד 12+ רגיל) ייתכן שיידרשו הרשאות מערכת
  (`BLUETOOTH_PRIVILEGED` — מוצהר במניפסט), שורש, או ROM מותאם.
  מצב "נתמך/לא נתמך" מוצג בטאב ההגדרות → כל הגדרות החיבור → אבחון.
- איכות השיחה תלויה במרחק בין הנגן לטלפון הכשר (בלוטוס קלאסי ~10 מטר בתוך הבית).
- שיחות יוצאות עם קידומת כפי שהוזנה — רצוי מספרים בפורמט `+972...`.
- **הודעות SMS לא מגיעות לנגן** — פרוטוקול HFP מעביר שיחות בלבד (העברת SMS דורשת פרוטוקול MAP, שנתמך רק בחלק קטן מהטלפונים).
- במכשירים עם אכיפה הדוקה של אנדרואיד 14+ השיחה הנכנסת עשויה להופיע כהודעה מוקפצת (heads-up) במקום מסך מלא — לוחצים עליה ונפתח מסך השיחה.

## בנייה

```bash
gradle :kosherbridge:assembleDebug
```

קובץ ה-APK ייווצר ב-`kosherbridge/build/outputs/apk/debug/`.

> **בנייה מקומית דורשת את `debug.keystore` בשורש הפרויקט** (אותו קובץ שה-CI משחזר
> מה-secret). אם הקובץ חסר, הבנייה נכשלת עם "Keystore file not found". כדי ליצור
> אותו מקומית מריצים פעם אחת:
> `keytool -genkeypair -v -keystore debug.keystore -alias androiddebugkey -keyalg RSA -keysize 2048 -validity 10000 -storepass android -keypass android -dname "CN=Android Debug,O=Android,C=US"`
> ⚠️ מפתח שנוצר מקומית **שונה** מהמפתח של ה-CI — APK שנבנה אצלך במחשב לא יתעדכן מעל
> APK מה-CI (ולהפך). להתקנה על המכשיר עדיף תמיד להוריד את ה-APK מהריצה האחרונה בגיטהאב.

## עדכונים (בלי להסיר את האפליקציה)

כל APK שנבנה ב-GitHub Actions נחתם עם **אותו מפתח קבוע** (`debug.keystore` שמשוחזר
מה-secret `DEBUG_KEYSTORE_BASE64`), וה-`versionCode` נגזר אוטומטית ממספר ה-commits
כך שהוא תמיד עולה. לכן:

- **עדכון = פשוט מתקינים את ה-APK החדש מעל הקיים** — מהריצה האחרונה בגיטהאב
  (ארטיקט `kosherbridge-apk`). אנדרואיד מזהה עדכון ושומר את כל הנתונים (אנשי קשר, יומן).
- **לא להסיר לפני עדכון**, אלא אם המכשיר אומר שהחתימה לא תואמת — זה יכול לקרות רק
  אם הגרסה המותקנת נחתמה במפתח אחר (למשל APK שמורידים ממקום אחר או build מקומי),
  ובמקרה כזה נדרשת הסרה חד-פעמית.
- ה-secret `DEBUG_KEYSTORE_BASE64` נמצא בהגדרות המאגר (Settings → Secrets and variables → Actions).
  **שומרים עליו!** איבוד שלו = עדכונים עתידיים לא יוכלו להתקין מעל גרסאות קיימות.

## הפתרון הסופי — מודול Magisk לנגנים מרוטים

האמת היסודית: בלי רוט, אנדרואיד חוסם לצמיתות את שתי החומות הדרושות לשיחה מלאה
(API נסתר + הרשאת בלוטוס מיוחסת). Shizuku עוקף אותן אבל **חוזר לפעול רק אחרי
הפעלה ידנית אחרי כל אתחול** (אלא אם יש רוט).

עם רוט בנגן יש פתרון **מתקינים פעם אחת — עובד לנצח**: מודול Magisk שמתקין את
האפליקציה כאפליקציית מערכת (priv-app) עם `BLUETOOTH_PRIVILEGED` ומבטל את חסימת
ה-API הנסתר — אז פרופיל הדיבורית עובד באפליקציה עצמה, כולל קול, כולל אחרי אתחול,
בלי Shizuku ובלי adb.

- המודול נבנה אוטומטית ב-CI עם כל גרסה — ארטיקט **`kosherbridge-magisk-module`**.
- בנייה מקומית: `sh magisk-module/build.sh`.
- הוראות מלאות: [`magisk-module/README.md`](../magisk-module/README.md).
