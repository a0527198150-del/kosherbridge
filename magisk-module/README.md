# מודול Magisk — גשר כשר (פתרון סופי לנגנים מרוטים)

מודול זה הופך את התקנת האפליקציה על נגן מרוט ל**"מתקינים פעם אחת — עובד לנצח"**:
האפליקציה מותקנת כאפליקציית מערכת (priv-app) עם הרשאת `BLUETOOTH_PRIVILEGED`,
ונחסמת חסימת ה-API הנסתר של אנדרואיד — כך שפרופיל הדיבורית (HFP) עובד
באפליקציה עצמה, בלי Shizuku ובלי adb, וגם אחרי אתחול של הנגן.

## למה זה הפתרון הסופי

בלי רוט, אנדרואיד חוסם שתי חומות שאי אפשר לעקוף לצמיתות בתוכנה:
1. **API נסתר** — פרופיל הדיבורית (BluetoothHeadsetClient) אינו חלק מה-SDK הציבורי.
2. **הרשאת בלוטוס מיוחסת** (`BLUETOOTH_PRIVILEGED`, `signature|privileged`) —
   ניתנת רק לאפליקציות מערכת.

מודול זה מסיר את שתי החומות בנגן מרוט:
- האפליקציה מותקנת ב-`/system/priv-app` + אישור ברשימת ההרשאות →
  מקבלת את `BLUETOOTH_PRIVILEGED`.
- `service.sh` מפעיל בהפעלה `settings put global hidden_api_policy 1` →
  ה-reflection אל ה-API הנסתר מותר.

האפליקציה עצמה כבר יודעת לעבוד בדרך הישירה — המודול רק נותן לה את ההרשאות.

## איך בונים

המודול נבנה אוטומטית ב-CI עם כל גרסה (artifact בשם
`kosherbridge-magisk-module`). לבנייה מקומית:

```sh
gradle :kosherbridge:assembleDebug
sh magisk-module/build.sh          # נוצר kosherbridge-magisk-v1.zip
```

## איך מתקינים

1. **מרוטים את הנגן** (Magisk מותקן).
2. מעתיקים את קובץ המודול (`kosherbridge-magisk-v1.zip`) לנגן.
3. פותחים את אפליקציית **Magisk** → Modules → **Install from storage** → בוחרים
   את הקובץ.
4. **מאתחלים את הנגן.**
5. פותחים את האפליקציה — עכשיו "פרופיל דיבורית" צריך להראות **"נתמך"**
   באבחון, והחיבור עובד דרך הערוץ הישיר. בוחרים את הטלפון הכשר ומתחברים.

> אם הפרופיל עדיין מראה "לא נתמך" — בדקו באבחון שהאפליקציה מותקנת כמערכת
> (ערוץ פעיל: "ישיר") ואשרו שהמודול פעיל באפליקציית Magisk.

## מגבלה כנה

גם כמערכת, **ערוץ הקול (SCO) תלוי בשבב הבלוטוס של הנגן**. בנגנים עם
מחסנית בלוטוס תקינה (טלפונים, קופסאות איכותיות) הקול עובד; בשבבים זולים
שאינם תומכים ב-SCO כלל — השליטה עובדת אבל הקול לא, ואין תוכנה שתכריח זאת.
